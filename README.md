# ネットリテラシー・シミュレーター

友達から送られてきたURLやファイルを、どこまで無警戒に開くかを安全に体験してもらう教育用デモです。

## 特徴

- GitHub Pagesでそのまま公開可能
- 外部サーバー不要
- 個人情報・パスワード・Cookieを収集しない
- 危険なファイルやマルウェアを使用しない
- 行動記録は参加者自身のブラウザの `localStorage` にのみ保存
- URLクリック → ダウンロード → 結果表示、という簡単な流れ

## GitHub Pagesへの設置

1. GitHubで新しいPublicリポジトリを作成
2. このフォルダ内のファイルをアップロード
3. Settings → Pages
4. Sourceを `Deploy from a branch`
5. Branchを `main` / `/ (root)` にして保存
6. 表示されたURLを友達に送る

## 重要な制約

この版では「誰がクリックしたか」を管理者側では識別できません。
行動記録は各参加者のブラウザ内だけに保存されます。

友達のIPアドレス、メールアドレス、ログイン情報、Cookieなどを収集する機能は入れていません。

## 実験の使い方

このリンク（`index.html`）を、Discordなど普段のチャットで直接友達に送ります。

例:
「これ昨日見つけたｗ 普通におもろいから見てみて」

相手がリンクを開くと、いきなり動画ページが表示されます。
読み込み中のカクつき演出のあと「再生できません」というエラーになり、ダウンロードを促す流れです。

「メッセージ画面」は用意していません。メッセージ自体は実際のDiscordなどで送ってもらうことで、リンクを踏むかどうかそのものを測定する設計です。

ダウンロードボタンを押すと `assets/test-file.txt`（安全なダミーファイル）が保存されます。

行動記録を確認したい場合は `result.html` を別途開いてください。

## 発展

管理者側で匿名の集計をしたい場合は、参加者本人を識別できないランダムなセッションIDと、クリック等のイベントだけを保存するバックエンドを追加できます。

ただし、実験対象者には「教育用テストであること」と、何を記録するかを明示する方式を推奨します。
